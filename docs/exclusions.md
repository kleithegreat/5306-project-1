# Exclusions (M5)

Snapshot **2026-09-18**. Generated by `src/exclusions.py`. Do not hand-edit.

Exclusions are boolean columns on the frozen contributor table, not deleted rows.
`src/exclusions.py:analysis_sample()` is the only way downstream analyses get a
sample, so nothing can quietly use a different one.

**343,176 authors in the frozen table → 322,094 in the analysis sample** (93.9%).

Exclusions overlap, so the first column does not sum to the total removed. The
second column counts authors this exclusion alone is responsible for.

**`excl_api_author`** — AI note writers. Matched on the `api` prefix rather than `apiEarnedIn` exactly, so `apiEarnedOut` and `apiTestUser` are caught if they ever appear. An AI that stops writing has not given up, which is the thing we are measuring.

**`excl_pre_2023_cohort`** — `firstNonNMRStatus` is empty for every note created before 2022-05 and the rest of 2022 is contaminated by the 2023-01-20 retro-scoring, so these cohorts cannot supply a Not Helpful group to compare against.

**`excl_first_note_unscored`** — First note has no `noteStatusHistory` row, so its outcome is unknown rather than absent. Calling these NMR would inflate the comparison group by an amount that grows over time and would show up as a fake cohort trend. Decided after Gate 1, delegated by Kevin; see docs/worklog.md.

## Carried but not applied

**`flag_not_misleading`** — Notes calling a post not misleading are structurally barred from Helpful: since 2023, 164 reached Helpful against 57,777 Not Helpful. Kept in the primary analysis at Gate 1, reported separately as robustness.

In the analysis sample: 80,663 authors.
