# Survival curves (M6d)

Generated by `src/analysis_survival.py`. Curve data in `out/tables/km.csv`.

## Censoring rule

Follow-up starts at the day-7 landmark. The event is the author's next note, at `second_note_at − landmark_at` in days. An author with no next note is censored at `data_cutoff_at − landmark_at`, where `data_cutoff_at` is 2026-09-16, the newest note in the snapshot — not the 2026-09-18 snapshot date, because releases only contain notes created up to 48 hours earlier. Durations are floored to whole days.
